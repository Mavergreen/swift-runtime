This installs a Swift core runtime (libswiftCore.dylib) built from swiftlang/swift source for OS X 10.9, into /usr/local/mavergreen/swift-runtime/lib/swift/.

It lets Swift command-line / computational programs built for x86_64-apple-macosx10.9 run on this Mac. It is not a full app runtime yet — the Foundation / AppKit overlays are a separate component.
